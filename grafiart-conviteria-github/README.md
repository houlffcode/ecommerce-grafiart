# Grafiart Conviteria — Protótipo

Frontend demonstrativo em React + Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Criar versão de produção

```bash
npm run build
```

## Publicar no GitHub Pages

1. Envie os arquivos para um repositório no GitHub.
2. A forma mais simples é importar o repositório na Vercel ou Netlify.
3. Build command: `npm run build`
4. Output directory: `dist`

## Observação

O carrinho e a navegação são demonstrativos. Pagamento, frete, autenticação, banco de dados e painel administrativo exigem integração posterior.
